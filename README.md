# 全国神社辞書

National Jinja Dictionary — 各都道府県神社庁の公式掲載情報に基づく、出典付き共通データと複数の日本語入力システム向け辞書を作成するPythonプロジェクト。

旅行先の神社名や難読名の入力を助けることを目的とし、件数より名称・読みの正確さと変換候補の使いやすさを優先します。

## 収録の原則

- 各都道府県神社庁公式サイトに掲載されている神社のみを対象とします。
- 初版の表記は神社庁掲載名とし、寺院、通称・略称、祭神名、宗教用語などは登録しません。
- 名称と読みは実際の資料に基づいて確認します。読みが神社庁にない場合だけ、当該神社の公式サイトで補完します。
- 読みが裏付けられない施設は辞書に出力しません。推定やLLMの記憶は根拠にしません。
- 異体字・旧字体と原文を保存し、全角ひらがなへの機械的変換と読みの推定を区別します。
- 同名施設は所在地で区別し、施設レコードと辞書登録レコードを分離します。
- 出力の重複除去は読み・表記・出力先品詞の組み合わせに限り、施設と出典は共通データに残します。

## 初版の出力対象

ATOK、Google日本語入力、Mozc、Microsoft IME、macOS標準日本語入力の追加辞書、出典・所在地・検証状態を含む汎用JSON・CSV。

いずれも対応予定です。公式資料または公式実装で仕様と対象バージョンを確認してから実装します。Google日本語入力とMozcの互換性は未確認です。macOSの追加辞書をテキスト置換・ユーザ辞書と同一扱いしません。iPhoneへの直接取り込みやAppleデバイス間同期は対象外です。

## 開発方針

1. 各神社庁サイトを実際に開き、公式性、一覧、項目、取得方法、利用条件、robots.txtを調査する。
2. 各IMEの公式仕様と対象バージョンを調査する。
3. 調査で判明した制約を反映し、読みと所在地が掲載される1都道府県の50〜100施設を上限に試作する。
4. 抽出結果と出典、各形式の自動検証を照合してから地域ごとに拡張する。

Pythonの最低対応バージョン、依存関係、セットアップ・再生成コマンドは実装時に確定します。現時点で実行可能な生成手順はありません。

調査台帳・作業ログ・進捗・個人のローカル環境情報はObsidianで管理し、この公開リポジトリには保存しません。公開成果物の出典・検証状態とは分けて扱います。
