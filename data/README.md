# 辞書の正本データ

`data/sources/*.json`を正本としてGitで管理します。各ファイルは神社庁または区別された参考資料の掲載情報を保存し、`facilities`（施設）と`entries`（読み・表記）を分離しています。原文、所在地、出典URL、取得日、確認根拠、検証状態を含みます。正本はObsidianに置きません。

- `manifest.json`：47都道府県の収集範囲・未完了理由。施設数と掲載総数を区別します。
- `source_catalog.json`：47都道府県の公式性・掲載項目・取得方法・利用条件の公開用情報源一覧。
- `corrections.json`：原文を保持した、実資料による名称・読み・外字の補正と保留候補。
- `decisions.json`：原文を上書きしない、人手の修正・除外判断。
- `source_aliases.json`：同一施設の重複掲載を原ID・原文hash・出典で束縛した整理。元掲載レコードを削除せず、施設件数と掲載観測数を分けます。
- `identities.json`：改称・移転等を実資料で確認した施設IDの対応。

集約した共通データは正本ファイルからメモリー上で生成します。重複する別の正本を持ちません。生成辞書はリリース時に正本から作り直してGitHub Releaseへ配布します。

取得したHTML・画像・キャッシュ、個人の作業ログをこのディレクトリーに入れません。原ページを複製する代わりに、辞書作成に必要な名称・読み・所在地と短い検証記録を保持します。

コードのMITライセンスと収集元データの利用条件は別です。出典別の条件を正本・manifestへ記録し、許諾を未確認のものは許諾済みと表示しません。明示的な利用禁止等で収集を停止した神社庁資料は取得せず、利用者が認めた参考資料も別区分として記録し、神社庁掲載へ置き換えません。
