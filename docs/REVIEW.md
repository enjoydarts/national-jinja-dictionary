# 未確認データ

読み・名称・所在地を確定できない登録は正本に残し、IME辞書への出力を保留します。

全件解決の完了条件は、対象登録の読みと同一性に必要な根拠が揃い、正本の検証を通ることです。資料不足・資料衝突・取得停止を、調査済みという理由だけで確認済みや除外へ変更しません。`reading_research.json`の`completion_tracking`に基準と進捗を記録します。

| ファイル | 内容 |
| --- | --- |
| [reading_research.json](../data/reading_research.json) | 未確認登録のID、名称、所在地、調査範囲、理由 |
| [corrections.json](../data/corrections.json) | 補正候補と資料の相違。`needs_review`は未採用 |
| [reviews.json](../data/reviews.json) | 採用済みの編集判断と根拠 |
| [manifest.json](../data/manifest.json) | 県別の未収集・未確認範囲 |

`reading_research.json`の`source_assessment`には、対象原文に対応する資料URL・hash、確認した表示、不足する根拠、残る判断事項を保存します。`bounded_source_review_completed`は記録した資料の点検を区切った状態です。読みや施設を確定できない登録は引き続き`pending`とし、辞書へ出力しません。追加資料の発見や編集判断によって再開できます。

追加の個別資料点検は`additional_source_reviews`に、対象原文hash、実際に確認した名称・読み・所在地、相違、不足、取得停止理由、次に必要な根拠を追記します。実リンク先の限定点検や取得停止を、公式性・全文読みの確認済みとは扱いません。

判断待ちには、注記の位置づけ、名称・かなの区切り、資料間の所在地の相違、外字の対応などがあります。根拠不足には、全文読みの欠落、所在地の不足、実リンク先の閉鎖などがあります。件数と各施設の残課題は正本の一覧を参照してください。調査範囲は各記録に挙げた資料に限定し、ウェブ全体に資料が存在しないとは扱いません。

生成物の`pending.json`・`excluded.json`は施設・登録単位の一覧です。`source-reviews.json`は施設登録前の記事・掲載枠・同一性候補を含み、施設数とは区別します。

棚卸し時点の要判断207登録は、既存根拠から次の主課題に整理しました。その後の個別審査で14登録が解消され、新たに思子淵神社1登録の資料不整合、白山神社1登録の読み相違、富松神社・姫神社・嘯吹八幡神社3登録の公式アクセスとの番地相違、新殿神社1登録の所在地字名相違を確認したため、ここまでの追加調査後の要判断は199登録です。これに東松山市公開の市民大学資料で全文読み・町域・地番を目視確認できた3登録について、市名を資料全体のscopeから解釈した参照情報の表現審査を加え、現在の要判断は202登録です。分類は新たな読み確認ではなく、既存の保留・補正・除外判断を解除していません。

ほかの保留にも、資料に全文かながない、原所在地が町域まで、資料と字名・枝番が対応しない、取得制限・通信失敗・旧URLで本文を確認できない、といった残課題があります。自治体の公式一覧に掲載されたURLでも、転送後の本文が別自治体や民間サイトなら公式性を確認済みにしません。取得制限を別形式・別経路で回避せず、必要な根拠と未取得範囲を残します。

対象ID、資料URL、名称・全文読み・所在地の原文、確認日を示してください。表記や所在地が異なる場合は、同じ施設と判断できる根拠も必要です。原文を残した補正として保存し、資料の相違が解決できなければ保留を続けます。
