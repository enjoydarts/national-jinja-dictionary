# 判断が必要な項目

資料を照合しても確定できなかった項目です。回答は **「R001はA」** のように番号と選択肢で指定できます。判断後は根拠と対象行hashを正本の補正・判断ファイルへ記録します。未回答の候補は採用しません。取得原文は残します。

- **C：この施設を初版の辞書から明示的に除外する。** 元レコードと出典は保持する。

対象施設ID：`087c77f0-0bd4-53b8-92c8-e7b2311dcf16`。対象登録IDと原文hashは [`corrections.json`](../data/corrections.json) の同施設を参照してください。

## 全件の要確認・除外を見る

```sh
python3 -m njd validate
python3 -m njd build --formats mozc,json,csv
```

`dist/dictionaries/pending.json` と `excluded.json` が全件リストです。`national/json.json`・`national/csv.csv`に施設の所在地、掲載URL、原文、補正、理由が含まれます。`report.json`で県別の件数を確認できます。リリースZIPにも全件リストを含めます。

「神社庁に読み未掲載」「公式な掲載関係を未確認」「取得条件による停止」は、上の個別補正判断と区別します。資料不足の数千件をユーザーへ一括で読み当てするよう求めることはありません。新たな読みを根拠なく追加しません。

IMEの仕様確認待ち・実機取り込み待ちは [FORMATS.md](FORMATS.md)、地域ごとの未取得範囲は [SOURCES.md](SOURCES.md)を参照してください。
