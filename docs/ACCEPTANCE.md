# 初版の確認範囲と検証結果

47都道府県を対象とした、出典付き正本と辞書再生成プロジェクトの初版です。調査した各都道府県神社庁の公式掲載情報を中心に、利用できない地域の参考資料単独枠を区別しています。全国の全神社、全掲載の収集、全施設の読み確認を完了したものではありません。

施設管理レコードには未確認・除外を含み、テスト形式の掲載1件も原文を保持して除外しています。地域の実在施設総数とはしません。適格な登録数43,776と適格施設数43,762も異なります。正式名の個別登録が複数ある施設を、別施設として水増ししません。

| 未調査・補完調査未了 | 493 | 原文注釈・所在地不足・候補の未照合等が残り、十分な補完調査をしたとは扱わない |

分類と各登録の理由は [`reading_research.json`](../data/reading_research.json) に保存しています。国税庁の現対象照合は20県の保存済み資料、Wikipediaは47県の記録済みカテゴリ範囲です。カテゴリに一致する記事名がないことは、Wikipedia全体や他の資料に情報がない証明ではありません。未完了登録はすべてIME候補から除きます。個別に回答を求める根拠付きの案件は [REVIEW.md](REVIEW.md) に分けています。

岐阜は640/828の名称・読みgroup、2,861取得ページ、2,115管理レコードの途中範囲で初版を固定しました。2,110施設が適格、4登録が保留、1登録が除外です。17の既知の未到達hrefと後続索引が残ります。828は施設総数ではありません。今回の停止は収集範囲の区切りで、神社庁のアクセス拒否を意味しません。

奈良の本文一覧1,303施設は保持しています。公式ページが埋め込む外部地図は、robots応答がHTMLで方針を確認できず取得を止めており、そのデータを収録したとは扱いません。他県も含めた範囲・規約・停止理由は [SOURCES.md](SOURCES.md) と [`source_catalog.json`](../data/source_catalog.json)、県別件数は [`manifest.json`](../data/manifest.json) を参照してください。

## 出力と検証

| 形式 | 初版の状態 | 実際のIME取り込み |
| --- | --- | --- |
| Mozc | 公式実装に基づく直接出力・形式検査・少量サンプル再生成 | 未実施 |
| macOS追加辞書 | 公式パーサー等に基づく直接出力・形式検査・少量サンプル再生成 | 未実施 |
| JSON・CSV | 出典・所在地・検証状態を含む直接出力 | 管理用 |
| ATOK | 書き出し実サンプルの文字コード等が不足、保留 | 未実施 |
| Google日本語入力 | リリース製品のインポート仕様・対象版の確認不足、保留 | 未実施 |
| Microsoft IME | 公式の一括取り込み構文・対象版等の確認不足、保留 | 未実施 |

品詞・文字コード・制限と不足情報は [FORMATS.md](FORMATS.md) に記載しています。Google日本語入力とMozcの互換性は無条件に仮定しません。macOSは追加辞書の対象で、テキスト置換・iPhoneへの直接取り込み・他デバイス同期の確認ではありません。

初版の確認では、自動テスト531件、正本の必須項目・読み・出典・状態等の検証、取得済み原文との照合、実データから選んだ少量サンプルの二度の生成で同一bytesとなることを確認しました。直近の追加分は、岐阜300掲載の詳細・検索href・所在地と、Wikipedia26候補の本文・所在地・版を個別照合しています。既存1,815件の岐阜施設・登録は全項目を保持しています。

独立監査では、47県の状態と出典区分、未完了ID・件数・分類と実施済み資料の整合、少量サンプルの形式・再現性、元データ・既存判断の保持を確認しました。全施設を今回新たに全件再閲覧したという意味ではありません。最終の検証結果と正本は同じコミットのCIで確認できます。

全国・県別の配布ファイルはリリース時に正本から新規生成します。この初版の確認作業では新しいタグ・Releaseを公開せず、更新済み正本・再生成処理・検証範囲を確定します。再生成・取り込み・未完了の再開方法は [README](../README.md) に記載しています。ソースコードのMITと、Wikipedia・国税庁・CODH等の資料の利用条件は区別します。
