# 情報源と収集範囲

47都道府県を対象とした公開情報源の一覧です。公式性の本文確認、実際の収集、施設・読みの検証を区別します。詳細は [source_catalog.json](../data/source_catalog.json)、施設ごとの根拠と原文は [正本データ](../data/sources/) にあります。

初期調査の掲載項目・範囲説明は `initial_survey`、その後の収集結果は `collection` に保存しています。初期調査時点の「未確認」「1ページ目のみ」は後の収集範囲を表しません。`evidence_pages` のエラーや未取得URLを本文確認済みとして扱いません。

公式神社庁サイトの本文確認は 44 都道府県、施設正本があるのは 47 都道府県です。神社庁資料の41県と、参考資料単独の6県を区別しています。47県に施設正本があることは、各県全神社の網羅や47県の神社庁本文確認を意味しません。取得数は掲載総数・地域内全神社数・辞書行数ではありません。

ソースコードとプロジェクト文書のMITライセンスは、収集元データの再利用許諾を意味しません。神社庁由来資料の公開辞書への再配布許諾は未確認です。Wikipedia参考資料枠は出典・版とCC BY-SA 4.0を保持します。利用条件の対象を確認し、情報の利用を広く禁じる地域や取得方針を確認できないアクセスは停止しています。記事・写真のみを対象とする記載は、名称・読み・所在地の事実項目と区別して記録し、再配布許諾があるとは扱いません。robots.txtの取得成功や404も再配布許諾とは扱いません。本文・画像・取得キャッシュはこの一覧に含めません。

「収集」は開いた公開掲載範囲の保存を表します。部分収集、条件による停止、公式URL未特定を明示します。千葉県は神社庁の指定する外部検索として、県立中央図書館の現行URL案内と検索入口の監修表示を照合しました。神社庁自身の運営や委託契約を確認したという意味ではありません。旧ホストのrobots判定不能は回避していません。大分・宮崎の公式URLは未特定、徳島の候補本文は未確認です。愛知は初期調査の部分確認を保持したうえで、2026年11月9日に実閲覧した神社新報社の名称付きリンクと、リンク先自身の庁名・著作権表示・検索の公開目的を突き合わせて公式性を確認しました。運営者住所は未確認です。

## 兵庫の地図検索範囲の比較

公式`formsearch.js`の`map.getBounds()`と4座標パラメータを実見し、既存の選択矩形と4つの重なる矩形のXML応答を比較しています。4応答は合計4053観測、重複219観測を除いた3834施設コードが既存と一致しました。各応答の座標範囲、同一コードの名称・所在地も照合しています。応答URL/hash/取得日・比較結果はsource_catalogの`map_partition_audit`へ保存し、本文XMLを配布しません。

これはプロジェクトが選択した検索条件の比較です。実ブラウザの表示範囲、現在の県境、APIの上限がないこと、地図に未掲載の施設を含む全神社数は確認していません。比較の一致をそれらの確認済みに読み替えません。通常の収集・生成はこの任意監査を自動実行しません。

```sh
# 同じHTTPキャッシュを再利用。施設正本や辞書を変更しない任意監査
python3 -m njd.adapters.hyogo --report /tmp/hyogo-map-audit.json
# 保存済み応答だけで同じ監査。独自キャッシュの場合は--cache-dirを指定
python3 -m njd.adapters.hyogo --offline --report /tmp/hyogo-map-audit-offline.json
```

意図的な再確認時だけ`--refresh`を使用します。2秒間隔・30秒timeout・再試行0回で、最初の取得失敗で後続検索を止めます。認証・robots・転送・チャレンジの防御を維持し、4つの明示条件以外の任意検索を解放していません。
