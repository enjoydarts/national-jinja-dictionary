# 情報源と収集範囲

47都道府県を対象とした公開情報源の一覧です。公式性の本文確認、実際の収集、施設・読みの検証を区別します。詳細は [source_catalog.json](../data/source_catalog.json)、施設ごとの根拠と原文は [正本データ](../data/sources/) にあります。

初期調査の掲載項目・範囲説明は `initial_survey`、その後の収集結果は `collection` に保存しています。初期調査時点の「未確認」「1ページ目のみ」は後の収集範囲を表しません。`evidence_pages` のエラーや未取得URLを本文確認済みとして扱いません。

公式神社庁サイトの本文確認は 44 都道府県、施設正本があるのは 47 都道府県です。神社庁資料の41県と、参考資料単独の6県を区別しています。47県に施設正本があることは、各県全神社の網羅や47県の神社庁本文確認を意味しません。取得数は掲載総数・地域内全神社数・辞書行数ではありません。

ソースコードとプロジェクト文書のMITライセンスは、収集元データの再利用許諾を意味しません。神社庁由来資料の公開辞書への再配布許諾は未確認です。Wikipedia参考資料枠は出典・版とCC BY-SA 4.0を保持します。利用条件の対象を確認し、情報の利用を広く禁じる地域や取得方針を確認できないアクセスは停止しています。記事・写真のみを対象とする記載は、名称・読み・所在地の事実項目と区別して記録し、再配布許諾があるとは扱いません。robots.txtの取得成功や404も再配布許諾とは扱いません。本文・画像・取得キャッシュはこの一覧に含めません。
