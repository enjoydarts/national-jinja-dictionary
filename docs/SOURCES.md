# 情報源と収集範囲

47都道府県を対象とした公開情報源の一覧です。公式性の本文確認、実際の収集、施設・読みの検証を区別します。詳細は [source_catalog.json](../data/source_catalog.json)、施設ごとの根拠と原文は [正本データ](../data/sources/) にあります。

初期調査の掲載項目・範囲説明は `initial_survey`、その後の収集結果は `collection` に保存しています。初期調査時点の「未確認」「1ページ目のみ」は後の収集範囲を表しません。`evidence_pages` のエラーや未取得URLを本文確認済みとして扱いません。

公式神社庁サイトの本文確認は 44 都道府県、施設正本があるのは 41 都道府県です。調査対象47県と収集済み県数は異なります。取得数は掲載総数・地域内全神社数・辞書行数ではありません。

ソースコードとプロジェクト文書のMITライセンスは、収集元データの再利用許諾を意味しません。各情報源の公開辞書への再配布許諾は未確認です。利用条件の対象を確認し、情報の利用を広く禁じる地域や取得方針を確認できないアクセスは停止しています。記事・写真のみを対象とする記載は、名称・読み・所在地の事実項目と区別して記録し、再配布許諾があるとは扱いません。robots.txtの取得成功や404も再配布許諾とは扱いません。本文・画像・取得キャッシュはこの一覧に含めません。

「収集」は開いた公開掲載範囲の保存を表します。部分収集、条件による停止、公式URL未特定を明示します。千葉県は神社庁の指定する外部検索として、県立中央図書館の現行URL案内と検索入口の監修表示を照合しました。神社庁自身の運営や委託契約を確認したという意味ではありません。旧ホストのrobots判定不能は回避していません。大分・宮崎の公式URLは未特定、徳島の候補本文は未確認です。愛知は初期調査の部分確認を保持したうえで、2026年11月9日に実閲覧した神社新報社の名称付きリンクと、リンク先自身の庁名・著作権表示・検索の公開目的を突き合わせて公式性を確認しました。運営者住所は未確認です。

正本の `verified_facilities` は施設レコードの状態、`verified_entries` は登録レコードの状態です。読み未掲載の施設にも施設状態 `verified` があり、両者を混同できません。数値はこの一覧のスナップショットであり、正本更新時には再確認が必要です。

自動検証と実際のIMEへの取り込み確認は別工程です。この情報源一覧はIME取り込み済みを示しません。
