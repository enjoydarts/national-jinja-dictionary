# 小城町・千代田町の旧住所に束縛する読み照合

県の合併資料の1ページ(3)小城市・2ページ(10)神埼市で確認した、小城郡小城町→小城市小城町（2005-03-01）、神埼郡千代田町→神埼市千代田町（2006-03-20）の2接頭辞を既存の個別証拠照合へ追加する。

一般住所の置換や原住所更新は根拠のない対象へ波及するため採らず、固定PDFのURL/hash・ページ・施行日・表示例と施設/登録ID・原文hash・参照住所に束縛する既存方式を使う。これは実装判断であり、個別候補の採用承認ではない。字名・全地番・枝番は既存の全住所比較に任せ、小城町の晴氣/晴気・岩藏/岩蔵の変更を一般化しない。有田の地番再編も対象外。

高志神社・牛尾神社は、神社庁の原掲載、県PDF、月次・日次の全同名存続競合、登録全文カナを別々に照合する。高志神社の名称画像は画像ID/hashと行を束縛して独立目視審査する。原住所・原字形・施設ID・原文hashを保持し、採用する場合も読みのみ変更する。人工テストの通過は実施設の根拠には使わない。
