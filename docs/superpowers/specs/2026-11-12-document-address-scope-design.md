# 行政資料の区域を明示した所在地照合（承認待ち案）

目的は、行政の地域調査資料で市区名が省略されていても、同じ資料が対象区域を明示し、掲載名称・町名・全地番が正本と一致する場合に、その対応を検査可能な根拠として保存することである。読みは資料に印刷された全文かなだけを使用する。

## 方式

1. 推奨案：原文の `address_raw` を保持し、区域の確認記録を別フィールドへ保存する。同じURL・資料hashに束縛された区域の引用・掲載箇所・確認日時を必須とし、正本の市区名との一致と、残りの町名・全地番の一致を検査する。区域だけを省略した資料を扱えるが、確認記録を個別に作成する必要がある。
2. 現状維持：市区名から全地番まで同一行に載る別資料が見つかるまで保留する。検査仕様は変わらないが、今回全文かなを確認した山科区6件は保留が続く。

この文書は推奨案の承認前の提案であり、利用者が方式を選択・承認したという意味ではない。

## 推奨案の採用条件

- 対象は実本文で発行者と対象区域を確認した行政刊行物。発行者住所だけでは対象区域の根拠にしない。
- 読み・名称・町名・全地番が対応する行と、区域の説明は同じ取得資料に属する。異なるURL・hashの資料間の結合は認めない。
- 区域の引用、掲載箇所、確認日時、資料URL・SHA-256と、正本の対象市区を保存する。区域が資料の該当一覧に適用されることも確認記録に残す。
- 既存の原文住所・施設ID・名称・旧字体・補正や除外判断を保持する。住所原文に市区名を追記しない。
- 町名・字名・全地番の比較は既存の機械的な数字・番地表記比較だけを使用する。異体字や地名の推定置換を追加しない。
- 数字のない町域同士、地番省略・相違、別の市区を含む住所、別資料、行政刊行物以外、区域根拠の欠落・不整合は、この方式では採用しない。
- 法人種別を取り除いた名称照合や、別称への読みの流用をこの方式へ組み合わせない。

## 対象と検証

対象候補は `data/reading_research.json` に保留の根拠を保存済みの、山科区報告書の朝日神社・愛宕神社・八幡宮2件・山科神社・若宮八幡宮。PDFの原文・画像はコミットせず、短い事実項目・引用・確認記録を保存する。報告書6件の個別採否は、区域の実本文と各掲載行の再確認後に決める。

実装時は、既存の住所照合が自動的に緩くならないことを確認する。明示的な区域根拠を付けた正例に加え、別区域・違う町名/全地番・欠けた地番・資料hash/URL不一致・区域根拠の欠落を拒否するテストを先に作成する。全文テスト、`python3 -m njd validate`、旧補正と取得原文の不変性、対象以外の適格集合の不変性を確認し、日本語の機能単位コミットにする。

中黒の削除や読みの補作、異なる行政資料間での住所と読みの結合は対象外である。
