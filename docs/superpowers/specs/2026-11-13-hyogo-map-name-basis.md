# 原地図名に一致する登記を施設同定だけに用いる

継続指示に基づく兵庫の追加審査。原地図と原詳細の名称が異なる場合のprofile_name_selectionへ、registered_name_basis=mapを追加する。既存のdefault profile基準と所在地選択は変えない。

原地図の実codeから原詳細への公開リンク、原詳細の印字code、両者の完全な同一全所在地、原地図名に完全一致する一意の存続登記を束縛する。登記は施設の対応を確認する根拠だけであり、原詳細名の改称根拠や原詳細の発音の証拠とはしない。元の正式名や地図名の正誤・変更原因は認定しない。

出力は原詳細h1にある名称と同じ詳細の明示全文かなだけを選ぶ。原表示の宮を神社へ変えず、登録名へ宮を足さず、地図名へ詳細の読みを割り当てない。原全住所・原名・原かな・ID/hash・review_reasonを保存する。名称以外の同一性保留・除外・住所差・画像文字・source conflictsは解除しない。原XML観測は単一、実公開JSのcodeリンクと全地番を確認する。新map基準では登記カナが空の場合のみ扱い、別名のカナを流用しない。

既存の兵庫月次20261030全206383行、20261112までの8日次19178行、対象法人/全地番イベント0に拘束する。空欄の登記カナや別施設の読みから発音を推定しない。コード・原文hash・印字code・全地番・地図名/登記名・3根拠と状態窓を再適用及びoffline validateで検証する。新しい同定資料で矛盾すれば再審査する。

実採用候補は駒宇佐八幡宮6306046の1元登録。原詳細は駒宇佐八幡宮/コマウサハチマングウ/三田市上本庄1221、原地図と法人9140005015467は駒宇佐八幡神社/同全地番で対応する。本文でも同じ主対象に両名称が現れることを最小の事実として確認する。施設統合は行わない。

同時に残14登録の原詳細名/原地図名・原全住所を名称先行と住所先行で限定再点検し、該当住所候補と別所在地同名候補の件数を区別して保存する。原地図の篠山市接頭辞の条例比較は発見リードに限る。語順に疑義のある3かな、宮社とジンジャの対応に疑義がある1件、住所欠落や字形/第三名称の差はこの型で解除しない。全国の残保留と実IME取込は未完了として記録する。
