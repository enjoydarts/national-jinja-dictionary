# 同記事の明示省略宣言による比較住所

対馬神社カテゴリの実リンク39記事をrobots準拠で通常取得し、本文テキストを点検した。津和原神社は全文かなと全住所が同欄にあり既存補正で扱える。天神多久頭魂神社（富浦104）は記事9668の「※以下、長崎県対馬市を省略」、屋利止加神社（鑓川290）は記事9588の「（以下、長崎県対馬市を省略）」が直接本文段落に明記される。後者の印刷住所には地名の括弧かなが介在する。

`article_address_context.kind=same_article_explicit_omitted_municipality`を追加する。対象は個人調査記事の独立正式名全文かな付きh2と直後p。本文の直接子であること、本文要素数/省略宣言p/見出しh2/直後住所pの要素index、同一HTTPS URL/hash/確認日時、全原段落・完全見出しを束縛する。見出しは正式名＋全角括弧の全文かなに完全一致。県名/市名の宣言は施設の県/市と完全一致し、対象見出しより前にあることが必要。別記事カード・目次・祭神かな・同名別施設から合成しない。

住所原文・住所段落を保持する。比較時だけ明記された県市を足し、住所中に実在する1個の全角括弧ひらがな注記をUnicode区間で束縛して除く。町字は原字で完全一致し、数字と明示地番単位のみ既存の厳格な `_parcel` で比較する。枝番文字・字名不足・異体字・旧新地名を推定対応しない。省略宣言のない記事を市内記事という理由だけで承認しない。

PDF冊子型/市民大学型/CSV型へ記事を偽装する方法や、比較住所を印刷原文として保存する方法は採らない。読みだけ・非除外・既存同一性/公式性保留なしに限る。壊れたcontextは普通の有効参照が混在しても回避できず、反復適用時の除外保持と保存根拠の出力時再検査を行う。観測整合性の検証であり、HTMLの真正性や包括転載許諾の機械認定ではない。
