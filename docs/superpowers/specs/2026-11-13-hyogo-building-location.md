# 兵庫の所在地欠落と市文化財本殿の個別対応

原詳細/原地図とも住所空欄で、原詳細に郵便番号・正式名・全文かな・実codeがある登録に限る。洲本市教育委員会の文化財本殿資料の所有者/管理者名、所在地、再興/修理の異なる3年と構造を原詳細本文に拘束する。本文全体や市の建造物かなから読みを生成しない。

新所在地は市の明示欄だけから派生し、原空欄・郵便番号・地図・全原表記/hashを保持する。同名同郵便番号の唯一の存続登記を補助照合し、同じ字前地域と全地番、登記固有の追加字を分ける。追加字を市所在地へ補作しない。全月次/実8日次の固定窓を維持する。他の条件・衝突・外字・他code・住所変更・複数候補なら保留。

型はhyogo_cultural_building_location。njd/hyogo_building_location.pyが証拠を検証し、locationsの既存型は変えない。原神社庁全文かなの正規化だけを派生登録に設定する。再適用で新所在地を原住所と誤認せず、無効証拠なら原空欄へ戻す。validationで証拠改変を検出する。

実案件は鳥飼八幡宮6328164。資料の本文・画像・PDF・電話/個人名はコミットしない。市資料は最小の事実項目だけ記録し、博物館の転用禁止資料は採用しない。全国全件完了/実IME取込を主張しない。
