# 兵庫の原所在地選択審査

目的：同じ実コード・同じ正式名の地図と詳細に所在地差がある3登録を、実資料に拘束して同定し、原詳細の全文かなだけを出力する。資料はreading_research.jsonのhyogo_five_actual_address_fields_registered_parcels_and_kamikawa_admin_review_20261113と、実キャッシュのXML/詳細/公開JS/国税庁月次日次。佐佐婆神社6307008は原詳細の丹波篠山市畑宮377と登記の全名称/所在地/全文かなが一致する。XML篠山市畑宮376は保持し、原因・移転・旧番の認定はしない。天津神社6310104と八幡神社6310112は、同実コードが原詳細へリンクするXMLの字下馬場998/字峠698が登記の全住所に一致し、詳細は字名を含まない表記。推定の字名補完・一般的な字名除去を行わない。

検討した方法：相違原因の説明が見つかるまで全保留、又は独立登記と実リンク関係に基づく対象選択。後者を個別審査として採用する。原詳細の実名称・全文かなを用い、地図の別所在地にその読みを移したり両所在地の関係を推定したりしない。行政名欠落の神河2登録は別課題として維持する。

新review_kindはhyogo_profile_location_selection、confirmation=source_review、profile_selection_proof.kind=hyogo_typed_profile_registered_location_selection、selection=profile_name_and_profile_kana_with_location_evidence。既存の施設/登録ID・原文hash・実code・profile/map両原名に加え、profile_address_raw(〒を除く原詳細住所)・map_address_rawとregistered_address_basisを拘束する。両原名は完全一致し、両住所は異なる。理由はHyogo map and profile addresses differのみ。

basis=profileは登録の全住所が原詳細住所に一致する場合。basis=linked_map_additional_azaは、原詳細の完全な末尾数字地番の直前へ原XMLに明記された単一のadded_aza_raw（字又は小字＋非数字字名）を挿入した文字列がXML住所と完全一致し、登記全住所がXMLに一致する場合。数字の途中を分断した挿入・別字名・別地番・別codeは拒否。fの仮住所を作って同定関数を呼ばない。比較正規化は既存の数字幅/明示数字単位だけで、非数字の字形は保持する。

3参照はagency_profile/agency_map/registered_profile_identity。元hash/欄位置/〒住所/全文かな/印字code、元XML1観測、公開JSによるcode→profile実href、独立した同名全住所の唯一の存続神社法人を拘束する。既存の点検済み20261030～20261112窓（兵庫206383行・全国日次19178行）と対象イベント0・取得/確認/承認時刻の順序検証を共用。Govカナがあれば原詳細の全文かなと一致、空欄から読みを生成しない。

原正本bytes・原名/住所/かな/ID/hash・旧map/profile観測・review_reason・過去判断を保持。出力は原詳細名＋原全文かなの機械的ひらがな化1組、元reading_urlとagency_selectedのみ。住所・municipalityを編集しない。他のidentity flag、名称差との複合、外字、除外、原文変更は拒否。不正proofは共通splitへ進めず保留。再適用・オフライン検証でも再検査。依存追加なし・Python対象版は既存通り。実IME取り込みは別確認。
