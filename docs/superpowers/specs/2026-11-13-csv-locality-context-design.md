# 同一CSV行の所在地・小字による照合

保留を解除するには、正式名の全文読みと原全住所を実資料に結び付ける。高知KUT公開CSV011には、所在地（市町村・大字・地番）と小字が同一行の別列として明示される。両原値を保持したまま、比較時だけ「所在地の地番前接頭辞＋小字区切り＋小字列＋地番」を構成する。小字区切りは比較上の「字」又は空文字だけを許し、`comparison_separator` に判断を保存する。小字の値は同一行の列そのものを使う。

一般の住所省略規則を増やす方式や、原正本の小字を削除する方式では照合範囲が広過ぎる。同一CSV行の構造化証拠を追加する方式を採る（実装者の判断）。`csv_address_context.kind=same_csv_record_explicit_aza` にURL/hash/確認日時/論理行番号/No/原列値/抜粋を保存し、参照と一致する場合のみ使用する。原所在地・出典住所・原カナは書き換えない。`address_raw` は所在地列そのものとし、比較用住所を原文の連続引用とは扱わない。

対象は `university_hosted_community_research_csv` の明示された社名・全文カナ・所在地・小字の同一行。数字地番の既存比較だけを利用し、小字の綴り変更、漢字とカナの推定対応、旧村名や沿革からの補作、枝番文字・合番・複数地番の解釈を行わない。既存の除外・施設保留・同一性保留・名称変更は解除しない。不正なコンテキストから通常照合へ後退しない。

取得済み011の20近似候補を再点検し、この方式に厳密対応する行を採用する。他の差は記録して保留する。元CSV/本文/長い沿革/人物名はコミットしない。全旧履歴、基準10,868 ID/hash、原正本、対象外の実効データを保持し、各形式の自動検査と実IME未確認を区別する。
