# 同冊子番号と明示省略接頭辞の住所照合

対馬2017年3月冊子の候補12件を画像点検した。単独紹介8件は全文かな・神社番号と同番号/同名の鎮座地表が対応する。高御魂は表の豆酘2424番地ロと境内遷座記述の全地番対応が未解決。島大國魂/那祖師/若宮は3社合祀と各原地番の関係を追加確認する。4件は保留、他8件を個別採用する。

原住所の書換えや一般の部分住所一致ではなく、`booklet_address_context.kind=same_pdf_numbered_profile_explicit_prefix`を新設する。既存市民大学/CSV型へ観光冊子を偽装しない。PDFの同一URL/hash/確認日時、総頁数と0起算頁位置、単独紹介の番号/正式名/全文かなと一覧の同番号/正式名/原鎮座地、町名見出し/省略宣言を束縛する。原画像hashと個別点検済みの記録も必要。元住所は県名以外も全字完全一致とし、省略接頭辞+印刷鎮座地を比較するだけ。名前・町字・旧字体・枝番の近似照合は追加しない。

紹介名の地名括弧は別の注記欄へ保存し、同じ原鎮座地の先頭文字列と対応させる。全文かなは社名部分として原画像に独立印字されたものだけ。三社連名や他の神社・祭神のかなはこの型の対象外。

不正な根拠は通常住所や他の有効参照へfallbackしない。読みだけの補正、未除外、施設同一性/公式性が未保留の場合に限定する。繰り返し適用しても既存除外理由を保持し、出力時も保存根拠を再検査する。これは観測の整合検査でありPDFの真正性/包括転載許諾の認定ではない。

既存型の流用は資料種別が異なり不適切、住所を加工して原文として保存する案は正本の規約に反するため採らない。ユーザーの自律完遂指示に基づき確認待ちを追加せず実装する。全原正本・旧判断・10868ID/hash・調査履歴を保存する。コード/文書MIT、取得本文/画像/認証情報はリポジトリへ入れない。
