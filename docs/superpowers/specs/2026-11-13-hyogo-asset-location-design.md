# 郵便番号だけの詳細を市の土地台帳と照合する

貴船神社6328113の原詳細・原地図には所在地がなく、原詳細の全文かなキブネジンジャと郵便番号656-1524は確認できる。今回、原詳細本文の竹谷という地名と、淡路市の令和6年度固定資産台帳p.3「事業用土地」の同じ行「所在地：竹谷496／資産名称：貴船神社」を確認した。国税庁の一意な同名/同郵便番号の存続法人5140005019620も同じ全地番である。

## 方法と制約

住所空欄を直接書き換える案や、登記だけで補う案は採用しない。新しいlocation supplement `hyogo_municipal_asset_location`で、原実code・原全文かな・郵便番号・原由緒の地名、同コードの原地図、実公開リンクに束縛した市の台帳の同一行、独立登記の完全な地番を検証する。

- 原詳細/原地図とも住所空欄、元の保留理由が所在地欠落だけである単一原登録に限定する。名称相違・部分読み・外字・別の既存判断・除外は解除しない。
- 由緒の「古来竹谷の明神として崇敬された。」という同じ主対象の地名観測を原詳細hashへ束縛し、別の同名神社へ流用しない。
- 市の台帳は558ページ中p.3の該当行を目視確認。資産名称と所在地を同じ行で照合し、隣の竹谷496-1や市道（貴船神社線）を所在地にしない。台帳の取得年月日を神社創建年、土地の資産記載を神社所有権の確定とは扱わない。
- 市名は市の公表主体、所在は台帳の所在地列から構成する。PDFに市名付き住所が連続印刷されているとは扱わず、原空欄・原地図・ID/hashを保持する。
- 兵庫20261030月次206383行と20261112までの8日次19178行をオフライン照合。同名/同郵便番号と全住所で同一の一意存続法人、関連変更0を要求する。登記カナ空欄は読みに使わない。原神社庁の全文かなのみを正規化する。
- 初回・適用後検証・再適用で同じ条件を満たす。不正型で例外終了せず、破損時は保留・出力停止。単一登録条件が破れたら施設全体の出力を止める。

## 資料の利用と限界

WebツールのPDFタイムアウト後、市の実掲載リンクとrobotsを確認し同一HTTPS URLを1回だけ通常取得した。拒否・別ホスト・別形式による回避ではない。市の一般著作権規定を資料全体の再配布許諾とせず、名前・所在地という最小事実項目と出典位置だけを保存する。原PDF/画像/全文・個人情報はコミットしない。並行点検の二子住吉神社は町資料と神社庁の創建年・字名が異なり、西濱神社は原地図名/登記字形の対応が残るので保留する。実IME取り込み・全国残件完了を主張しない。
